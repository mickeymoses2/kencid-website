# KENCID College website

Custom WordPress theme and site files for Kenya College of Interior Design.

## Local setup

1. Install WordPress and import the site database.
2. Copy `wp-config-sample.php` to `wp-config.php` and add local database credentials.
3. Place this directory in a PHP-enabled web server such as Apache/XAMPP.
4. Activate the **KENCID College** theme from WordPress Admin.

The local `wp-config.php`, uploads, QA captures, and generated exports are intentionally excluded from this repository.
